# SKILL_GOVERNANCA_DADOS.md

## Objetivo
Guiar tratamento de dados com foco em qualidade, ownership, rastreabilidade e semântica correta.

## Princípios
- todo dado importante precisa de origem clara
- metadado e versionamento são obrigatórios
- qualidade e responsabilidade devem ser explícitas
- não misturar dado bruto com dado de decisão
