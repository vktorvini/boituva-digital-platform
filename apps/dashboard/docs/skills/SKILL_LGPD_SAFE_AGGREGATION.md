# SKILL_LGPD_SAFE_AGGREGATION.md

## Objetivo
Garantir que domínios sensíveis sejam modelados de forma agregada e segura.

## Regras
- não usar dado individual no app executivo
- sempre preferir agregação
- evitar reidentificação
- usar grupos mínimos quando necessário
- educação e saúde devem nascer LGPD-safe
