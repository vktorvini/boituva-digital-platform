# SKILL_PRODUCT_THINKING.md

## Objetivo
Fazer o agente pensar problema, usuário e resultado antes de propor qualquer solução.

## Regras
- não criar feature sem problema claro
- priorizar impacto executivo
- antes de propor solução, identificar usuário, dor, decisão e resultado esperado
- produto bom melhora decisão com clareza e confiança
