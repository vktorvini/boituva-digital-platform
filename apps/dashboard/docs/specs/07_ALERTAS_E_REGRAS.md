# 07_ALERTAS_E_REGRAS.md

## Semáforo padrão
- Verde = OK
- Amarelo = Atenção
- Vermelho = Risco

## Regras iniciais
### Pressão fiscal
- até 0.15 → verde
- acima de 0.15 até 0.25 → amarelo
- acima de 0.25 → vermelho

### Execução
- acima de 0.80 → verde
- entre 0.70 e 0.80 → amarelo
- abaixo de 0.70 → vermelho

### Gap crescente
- crescimento recorrente → amarelo/vermelho
